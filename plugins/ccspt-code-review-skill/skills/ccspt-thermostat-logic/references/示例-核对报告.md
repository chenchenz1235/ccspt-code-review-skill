## 报警汇总

- ❌ 不符合（6 项）：#1 首次上电起始转速；#2 首次上电升速曲线缺失；#3 第二次开机起始转速；#4 第二次开机 30min 升速缺失；#5 开机次数门槛；#7 长时间运行加档依据与时间点
- ❓ 待确认（1 项）：#6 转速上下限取值（客户 1600~4320）
- ⚠ 超出要求（2 项）：#10 再启动确认 300s；#11 转速统一限幅

## 差异详情

**#1 首次上电起始转速**
- 客户：3900rpm
- 实现：4500rpm
- 影响：首次上电即按最高转速运行，能耗与噪声与客户预期不符
- 可否用参数对齐：否（4500 为模型内写死的常量，需改模型）

**#2 首次上电升速曲线**
- 客户：运行 15min→4200rpm；再 15min→4320rpm
- 实现：无升速段，全程 4500rpm
- 影响：客户要求的分段升速完全未实现
- 可否用参数对齐：否（需新增计时与状态）

**#3 第二次开机起始转速**
- 客户：3900rpm
- 实现：3100rpm
- 影响：第二次开机转速偏低
- 可否用参数对齐：否（3100 为模型内写死的常量）

**#4 第二次开机升速**
- 客户：30min 后升速至 4320rpm 至停机
- 实现：无该规则，转速由运行开机率实时加档
- 影响：长运行时的转速轨迹与客户要求不一致
- 可否用参数对齐：否

**#5 开机次数门槛**
- 客户：开机次数≥3 次后才按开机率调速
- 实现：第一次 / 第二次 / 第三次及以后三条路径已存在，但第二次开机已按 3.1 加档
- 影响：第 2 次开机即受开机率影响，与"≥3 次后"不符
- 可否用参数对齐：否

**#7 长时间运行加档**
- 客户：100 / 130 / 160min 各 +1 档（+300rpm），190min→4320rpm
- 实现：按运行开机率 Ron_run 加档（阈值 0.8 / 0.85 / 0.88），与运行时间无关
- 影响：运行时间的四个加档点均无法复现
- 可否用参数对齐：否（需新增运行计时逻辑）
