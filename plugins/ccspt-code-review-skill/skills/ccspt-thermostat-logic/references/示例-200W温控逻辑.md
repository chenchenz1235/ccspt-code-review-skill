# 示例200W温控逻辑/200W thermostat logic

> 仅演示格式；下述数值、状态码及版本未在本次发布中用原模型验证。0.85 边界按不重叠区间演示，实际归属须核对项目分支顺序。
> 依据：`refrigerator_ctrl_Trefrigerator.mdl`（Model Version 1.8905，最后修改 2026-06-18）
> 执行周期：Trefrigerator（50ms 一次）

温控器信号需连续保持 0.5s 才被确认；化霜信号只做 0.5s 确认后对外输出，不参与本章控制。

## 1 首次上电/First startup

上电后温控器首次闭合，压缩机启动，1 个控制周期后转速指令为 4500rpm，运行直至温控器断开。
温控器断开后压缩机立即停止，本曲线不再执行。

After the first startup, the compressor starts at 4500rpm and keeps running until the thermostat opens.
This ramp runs only once per power-up.

## 2 第二次开机/Second startup

温控器断开后压缩机立即停止并保持停机，等待温控器再次闭合。
温控器连续闭合 300s（5min）后压缩机重新启动，启动转速 3100rpm，运行中按 3.1 加档。
本次运行中温控器再次断开后，转到第 3 节执行。

On the second startup, the compressor waits until the thermostat has been closed continuously for 300s,
then restarts at 3100rpm and is boosted according to 3.1.

## 3 转速控制/Speed control

### 3.1 长时间运行/Long-time running

运行中按运行开机率 Ron_run 加档，转速 = 启动转速 + 加档值。

| 运行开机率 Ron_run | 转速调整/Speed |
|---|---|
| Ron_run＜0.8 | 不加档/No change |
| 0.8≤Ron_run＜0.85 | 加1档/plus 300rpm |
| 0.85≤Ron_run＜0.88 | 加2档/plus 600rpm |
| Ron_run≥0.88 | 直接升至最高转速/Go to maximum speed |

加档值实时更新并叠加到当前转速上，转速越高加档越少；实际转速受 3.4 限制。

### 3.2 开机率控制转速/Control startup rate to adjust speed

每次重新启动时，按上一周期的开机率 Ron 调整本次启动转速，调整量以 300rpm 为一档。

| 开机率 Ron/Startup rate | 下一周期转速/Speed of next cycle |
|---|---|
| Ron＜0.7 | 减1档/Reduce by 1 level（-300rpm） |
| 0.7≤Ron≤0.8 | 维持转速不变/Maintain |
| Ron＞0.8 | 加1档/Next level up（+300rpm） |

调整后的转速记录为下次启动的基准值，并受 3.4 限制。

### 3.3 开机保护/Startup protection

每次温控器断开压缩机停止工作后，到下一次压缩机开机之间的时间间隔≥5min。
实现为：温控器须连续闭合 300s（5min）后才允许再次启动。

Each time the thermostat disconnects and the compressor stops working, the time interval until the next
compressor startup is ≥5min: the thermostat must stay closed for 300s before restart.

### 3.4 转速限制/Speed limit

压缩机转速始终限制在 speed_min~speed_max 之间：计算值高于 speed_max 时按 speed_max 运行，
低于 speed_min 时按 speed_min 运行。

compressor speed range: speed_min~speed_max; values outside the range are clamped to the limits.

## 附：状态码/Thermostat state

| 码值 | 含义 |
|---|---|
| 10 | 待机 |
| 11 / 15 | 首次上电：启动 / 4500rpm 运行 |
| 20 / 21 | 第二次开机：停机 / 等待温控闭合 300s |
| 22 | 第二次开机：3100rpm 运行 |
| 30 / 31 / 32 / 33 / 34 / 35 | 第三次及以后：停机确认 / 重新启动 / 停机等待 / 停机 / 启动前 / 停机过渡 |
