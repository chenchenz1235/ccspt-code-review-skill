# 电机参数审核流程

由本 skill 的 SKILL.md 按需加载；版本检测与报告生成由本 skill 负责。本文件不是独立 skill。

控制框架通常稳定，衍生项目主要修改参数，部分项目还调整引脚和功能。优先复用参数字典，必要时追查实现；审核不默认授权修改固件。

## 必需输入与依据

正式项目审核必须先取得立项单，从中确认负载、电压等级、功率等级及客户要求。没有立项单，明确请使用者提供并暂停后续正式审核；可以继续规则整理、字典维护和基准比较。此门槛来自用户明确要求。文件命名不能代替项目事实。立项单缺少关键字段时请求补充，不以参数当前值推断需求。

默认目标为项目中的 `driver/mcu_project/param/matlab_variable.c`；`ctrl` 是独立工程，不能混用字典值或硬件资源。确认目标、板卡版本及参考文件身份。

文档已覆盖的规则以文档为主；未覆盖的采用用户补充。代码确认单位、倍率、映射、执行条件及动态覆盖。发现文档与实现冲突，报告差异。文档的“一般”“建议”和示例值只能产生核实提示；固定要求和实际约束才作为错误判据。

## 资料读取

- 开始审核时读取 [审核规则](review-rules.txt)，按涉及分组选择规则。
- 查询具体参数时，在 [参数字典](parameter-dictionary.csv) 中按名称搜索，包含函数、公式、单位、依赖及原始项目代码位置。该字典是样本索引，当前值不是通用默认值，备注提取不等于语义确认。原始引用行号在新项目中需重新核对。
- 处理 `paramN/testN` 时读取 [间接映射](indirect-mapping.csv)，还原实际含义再应用规则。
- 审核 RX13T 的 `matlab_calc_param_init` 时读取 [共同计算基准](rx13t-common.csv) 和 [差异及时间例外](rx13t-differences.csv)。来源及比较范围见 [基准来源](rx13t-provenance.json)。共同条目是有效直接赋值的共同公式或值，非完整控制流等价证明；同时检查条件、顺序、依赖和后续写入。共同公式不能冻结项目输入与计算结果。两份样本中的不同内容暂不作为固定要求。其他 MCU 不能套用 RX13T 基准。

原始调试资料优先在项目 `Parameter_Review` 寻找 `风机启动调试.docx`、`电机调试文档.xlsx`，后者的 `程序打包参数对照表` 是映射来源。需要原始上下文而资料缺失时请求补充，不虚构依据。

## 审核执行

### 确定性计算工具

使用 `scripts/calculate.py <目标matlab_variable.c> --output <结果.json>` 进行计算准备，无第三方依赖。
脚本支持简单顶层算术、间接参数解码、RX13T共同公式独立重算及部分明确关系检查。先确认RX13T适用性；其他MCU不能使用此基准结果。
默认计算模式不代表正式审核，不受缺立项单影响；`--mode audit` 会明确拒绝，正式审核由取得立项单后的完整工作流完成。
输出包含计算值、期望值、差异和未解析项；不要忽略未解析项或将其判为通过。Python数字运算仅用于静态估算，不等同C浮点和整数逐位仿真。脚本不执行输入代码，不模拟条件分支及运行动态写入。只实现部分规则，不替代原理图、周期核对及其余规则。
脚本的 metadata_checks 自动检查结构化分组数量、表单一致性、备注范围及明显缺失的可见备注。范围不一致应先报告“配置与元数据冲突”，不能直接要求将工程值改到错误备注范围内。
实审时追踪新参数、跨MCU信号链及所有运行覆盖；正常运行的通信覆盖需追溯；产测/FCT特殊模型覆盖默认通过，不提示。延时停机的推荐值按顺风能力计算，忽略代码偏移。基准数值相等不证明公式、条件或时序相等，检查代码差异。
如更新共同公式，同步 references；新增脚本规则必须对应已确认依据并做边界/变更验证。

建立项目公共信息表，记录立项单证据、负载、MCU完整型号、板卡、电机极对数与最高转速、功率管及采样、保护信号、外设资源和模型周期。未知项明确列出。硬件系数及继电器配置需原理图，温度保护点需硬件确认。

先检查表单一致性、分组数量、名称重复、备注范围和可见参数说明。中文及英文标识同时完全一致才判重名；去除注释赋值，应用校验参数不归入最后一个结构化分组。功能关闭仍保留基本元数据检查。

按字典识别参数。新增参数、含义不明确、单位或映射变化、代码版本变化、规则冲突及动态覆盖均触发必要代码追查。只读取相关条目，不将整份字典全部加载。未覆盖参数标为待核对，不能视为已通过。

交叉约束须覆盖启动、运行、切换和动态限制，尤其 is_max、软件/硬件过流、弱磁、电流/速度带宽及载波频率。比较电流前统一峰值/有效值和采样口径。电流保护间距没有已验证统一百分比，不自行发明；阈值先后不能保证所有故障都由软件先动作。

周期从时钟、中断配置、分频及条件调用核算。保护计数还需追查增量、清零、饱和及实际调用路径，不能仅做计数乘备注周期。允许调整五项时间阈值：single_phase_lose_phase_cnt、step_out_cnt、lose_phase_cnt、over_speed_cnt、linear_step_out_cnt；关联派生值和运行覆盖也需检查。

涉及控制带宽时结合电频率、实际执行周期、离散实现及延迟。没有文档或验证依据时提出核实项，不用猜测的统一比例直接判错。单电阻、直流风机输出环和谐波抑制暂不专项审核；谐波效果后续可在测试报告环节审核。

## 输出与迭代

结果区分：明确错误、经验风险、缺少依据、文档代码差异。每项包含位置、当前值或公式、适用条件、规则来源、代码/资料证据及核实建议。列出实际检查范围及未检查部分，不以“符合常识”作判错依据。

集中合并需要用户确认的工程经验，能从代码查到的信息自行查。规则外的发现作为新增建议，经用户确认后纳入；用户更新覆盖旧规则。追踪例外的项目、原因和适用条件，不把一次例外推广为通用规则。

字典和基准维护保留来源、哈希、确认状态及范围；更新源文件后重核受影响条目。维护规则时同步更新本 skill 的 references，避免项目草案与安装版不一致。

## 用户确认的报告与审核约定（2026-10-14）

- 默认交付独立离线HTML：按高/中/低排序，问题概览表，点击展开；严重程度与证据状态独立。功能/保护风险优先于元数据问题。
- 延时停机按顺风能力核实停机后立即重启风险，报告给出推荐参数值及原因。以顺风能力30%为例，建议stop_wr=0.3*speed_max；本例1700rpm推荐510rpm。此项忽略代码转速偏移，不将偏移加入推荐值。
- 本例850V母线过压阈值高于器件推荐工作上限已由用户接受，不再提示该项；不得推广成所有器件/项目都可忽略工作范围。
- 产测/FCT特殊模型覆盖参数与保护开关默认通过，后续不提示此类覆盖。
- MTPA开关被派生计算置为开启允许，不提示。
- 对外先显示真实含义和对应参数名：运行PLL阻尼mcu_pll_zeta，而非test14；回切转速mcu_pll_to_linear_wr而非test9；回切反电势pll_to_linear_emfq而非test10。内部保留映射以计算追溯。
- 参数与备注范围冲突合并成一个低优先级事项，展开表格展示参数、当前值、声明范围、位置、建议；不能按参数拆成大量主问题。
- paramN/testN的单位问题不提示；保留独立解码、公式和实际值关系检查。
